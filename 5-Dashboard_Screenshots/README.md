# Dashboard Screenshots

This folder contains screenshots of the final Power BI dashboard developed for the Logistics Delivery Performance Analytics project.

## Dashboard Pages

### 01 — Executive Overview

Provides a high-level summary of logistics performance, including:

- Total Orders
- Total Sales
- Total Profit
- Late Orders
- Late Delivery Rate
- Average Actual Shipping Days
- Average Scheduled Shipping Days
- Average Shipping Gap
- Monthly Sales Trend
- Monthly Late Delivery Trend
- Orders by Shipping Mode

### 02 — Delivery Performance

Provides detailed analysis of delivery performance across:

- Shipping Modes
- Regions
- Product Categories
- Customer Segments
- Delivery Performance
- Sales and Profitability

### 03 — Root Cause Analysis & Recommendations

Identifies:

- Key delivery problems
- Root causes of delays
- Business impact
- High-priority focus areas
- Recommended business actions
