# Power BI Dashboard

This Power BI dashboard analyzes logistics delivery performance across shipping modes, regions, categories, customer segments and delivery statuses.

## Dashboard Pages

### Page 1 — Executive Overview
Provides a high-level view of:
- Total Orders
- Total Sales
- Total Profit
- Late Orders
- Late Delivery Rate
- Average Actual Shipping Days
- Average Scheduled Shipping Days
- Shipping Gap
- Monthly Sales Trend
- Monthly Late Delivery Trend

### Page 2 — Delivery Performance
Analyzes:
- Delivery performance by shipping mode
- Regional delivery performance
- Category-level late delivery
- Customer segment performance
- Sales vs profitability
- Shipping mode and region risk

### Page 3 — Root Cause Analysis & Recommendations
Highlights:
- Key operational issues
- Reasons behind delivery delays
- Business impact
- Priority focus areas
- Recommended actions
