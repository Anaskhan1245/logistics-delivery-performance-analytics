# SQL Analysis

This section contains PostgreSQL queries used to analyze logistics delivery performance.

## Analysis Areas

- Data quality checks
- Order and customer counts
- Duplicate order analysis
- Delivery status distribution
- Late delivery rate
- Shipping mode performance
- Regional performance
- Category performance
- Customer segment analysis
- Monthly delivery trends
- Shipping gap analysis
- High-risk segment identification
- Estimated late orders
- Business impact analysis

## Database
PostgreSQL

## Key SQL Concepts Used

- GROUP BY
- HAVING
- CASE WHEN
- CTEs
- Window Functions
- RANK()
- FILTER
- DATE_TRUNC()
- Aggregate Functions
