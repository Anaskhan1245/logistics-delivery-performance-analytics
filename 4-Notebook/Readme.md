# Jupyter Notebooks

This folder contains Jupyter Notebooks used for data exploration, data cleaning, exploratory data analysis and logistics delivery performance analysis.

## Analysis Performed

- Dataset exploration
- Data quality checks
- Missing-value analysis
- Duplicate analysis
- Delivery performance analysis
- Shipping mode analysis
- Regional performance analysis
- Customer segment analysis
- Category-level analysis
- Shipping delay analysis
- Business insight generation

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Workflow

Raw Data → Data Cleaning → Exploratory Data Analysis → Business Insights → Power BI Dashboard
