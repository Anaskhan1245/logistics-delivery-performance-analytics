# 📂 Raw Dataset

The original logistics dataset is not included in this repository because of its large file size.

The dataset was used locally for:

- Data exploration
- Data cleaning
- Exploratory Data Analysis
- PostgreSQL database loading
- SQL business analysis
- Power BI dashboard development

## 🔄 Data Flow

Raw Dataset
↓
Python / Jupyter
↓
PostgreSQL
↓
SQL Analysis
↓
Power BI Dashboard

## 📌 Dataset Availability

Due to repository file-size limitations, the original raw dataset is not uploaded to GitHub.

The repository contains the complete analytical workflow, including Python notebook, SQL queries, Power BI dashboard and dashboard screenshots.
